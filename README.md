# 中文文档精简

**删空话，留信息。把绕口的中文改成读者看得懂、用得上的文档。**

作者：Cammy Shares · Skill 名称：`chinese-document-simplifier` · 版本：0.1.0

适合说明文、产品文档、方案、评审意见和工作记录。尤其适合这些请求：
“这段太长了”“减少 AI 腔”“少说空话”“解释得让人看得懂”。

## 它怎么改

- 先说结论或问题，删除没有信息的开场和重复总结。
- 把连续的抽象词换成明确的对象、动作和结果。
- 保留数字、单位、否定、条件、例外、责任和不确定性。
- 保留作者有依据的判断和自然语气，不把每份文档改成固定三点。
- 原文已经清楚时，可以不改；不承诺固定压缩比例。

## 看一个例子

**原文**

> 为了进一步赋能用户实现高效的信息流转闭环，在管理员开启导出权限后，成员可以导出最近 30 天的数据，但被删除的记录无法恢复。

**精简后**

> 管理员开启导出权限后，成员可导出最近 30 天的数据。已删除的记录无法恢复。

保留了权限前提、时间范围和不可恢复的边界。更多[虚构示例](examples.md)用于说明预期，不是模型评测分数。

## 下载与安装

在 [Releases](https://github.com/cammy-shares/chinese-document-simplifier/releases/tag/v0.1.0) 下载 `chinese-document-simplifier-v0.1.0.zip`。
解压后，将整个 `chinese-document-simplifier` 文件夹放入 Codex 的个人 Skills 目录：
默认是 `~/.codex/skills/`；若设置了 `CODEX_HOME`，则放在该目录的 `skills/` 下。
重新打开会话后调用：

```text
使用 $chinese-document-simplifier 精简下面这份文档。
保留事实、条件和我的判断；直接给修改后的正文。
[粘贴原文]
```

其他支持文件夹式 Skill 的工具可按各自规则加载 `SKILL.md`。
未验证所有工具的兼容性；不要把它当作自动写作检测器。
