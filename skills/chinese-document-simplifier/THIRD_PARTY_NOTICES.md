# 来源与第三方通知

本项目结合公开写作原则与场景化编辑判断。以下链接说明方法来源，
不表示原作者认可或认证本项目。公开示例均为本项目编写的虚构材料。

| 来源 | 参考内容 | 改动 |
| --- | --- | --- |
| [ASD-STE100](https://www.asd-ste100.org/) | 受控语言的基本思想 | 中文场景化组织，不分发标准全文 |
| [Fenng Tech Doc Style Chinese](https://github.com/Fenng/Tech-Doc-Style-Chinese) | [受控中文模块](https://github.com/Fenng/Tech-Doc-Style-Chinese/blob/bcb2c32ceb698469441deef37a75735e242f6d6e/references/controlled-technical-chinese.md) | 选取原则并重新表述 |
| [mzopedia Simplified Technical Chinese](https://github.com/mzopedia/simplified-technical-chinese) | 规范与词表中的中文歧义和术语方法 | 选取原则，重新组织，不附完整规范或词表 |
| [中文技术文档写作风格指南](https://zh-style-guide.readthedocs.io/zh-cn/latest/) | 通用技术写作背景参考 | 仅链接，不附原文 |
